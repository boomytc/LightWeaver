# LightWeaver

LightWeaver 是桌面视频制作工具。把已有视频、图片、旁白和字幕组织成片，在 Studio 中编辑与预览，再导出成片或可继续精修的项目。

可用于静帧讲解、多源剧情解说、原声高光混剪、文案找镜头和参考片匹配。同一项目可混用文字卡片、图片和视频片段，也可与外部 agent 协作编写与审核创作方案。

## 开始使用

如果已取得桌面包，解压后打开 LightWeaver。桌面包自带普通制作与交接所需的运行工具。先创建草稿、导入素材、添加场景，保存后点击 **制作**。

首次体验可只用图片或文字卡片，使用固定时长。这条路径无需配置模型。AI 画面观察、语音合成、转写和检索按需要启用，步骤见[用户指南](docs/user-guide.md)。

当前桌面包未签名、未公证。macOS Apple Silicon 已完成本机验收，其他平台的验证范围见[桌面客户端验收](docs/acceptance-desktop.md)。

## 从源码启动

准备 Node.js 22.13 及以上的 22.x 版本，或 24.x。在项目目录首次安装依赖：

```sh
npm ci
```

安装完成后，选择当前系统的启动入口：

- macOS：双击根目录的 `start.command`。
- Windows：双击根目录的 `start.cmd`。
- Linux：在终端运行 `./start.sh`。
- 已打开终端：运行 `npm start`。

脚本启动源码版桌面窗口。窗口出现后即可创建项目；缺少 Node 或项目依赖时，脚本会显示处理提示。源码启动所需的媒体工具、模型环境和打包步骤见[开发指南](docs/development.md)。

## 配置所需能力

在 **设置 → 模型与供应商** 中配置 ModelBest，采用预设后使用 MiniCPM-V-4.7-35B-A3B 观察画面、VoxCPM2 合成语音。本地转写、精确字幕与检索的权重和环境也从设置页分别配置。

项目支持导出视频、LightWeaver bundle、OTIO 和剪映草稿。保存与恢复、数据位置和故障处理见[用户指南](docs/user-guide.md)。

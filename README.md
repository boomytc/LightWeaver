# LightWeaver

LightWeaver 是一个在本地运行的桌面视频制作工具，帮你把已有视频、图片、旁白和字幕编排成片，在 Studio 里预览与微调，再导出成 MP4 视频，或导出为项目包、OTIO 时间线和剪映草稿继续精修。

无论是做静帧讲解、多源剧情解说、原声高光混剪，还是根据文案找镜头、照着参考片匹配素材，都可以直接在同一个项目里自由混排文字卡片、静帧图片和视频片段；需要时也可以把项目交给外部 agent 协作写文案、审方案和剪辑。

## 第一次做片

首页自带一个由三张文字卡片组成的示例项目（**我的第一支视频**），每张卡片默认 3 秒（30 fps 下固定 90 帧）。

打开示例后修改任意文字，点击右上角的 **保存并制作**（如果项目已经保存过，按钮会显示为 **制作**）。等任务完成后，点击提示条里的 **查看交付** 进入 **交付** 页，就能导出 MP4 成片。走完这条流程不需要配置任何 AI 模型、API Key，也不需要准备自己的素材。

首次从源码启动前，请先确保本机装好了 Node.js、FFmpeg、ffprobe 和 Chrome（如果使用 WorkBuddy，也可以直接让它按[运行指南](docs/development.md)准备环境并启动）。

详细的界面操作见[制作第一部短片](docs/quickstart.md)。想了解文字卡片、静帧、视频片段各自怎么算时长，以及创作方案怎么审核生效，见[场景、时长与采用](docs/concepts.md)。

## 产品与运行边界

- **保存、制作和导出各司其职**：
  - **保存** 只把你当前的编辑内容存成一条新的项目版本记录，不会改动以前导出过的任何文件。
  - **制作** 会按照保存好的项目内容和当前素材，渲染生成可播放的成片，并记录到项目的 **交付与历史** 列表里。
  - **导出** 则是把做好的成片（或项目包、OTIO、剪映草稿）另存到你指定的文件夹；重新制作不会覆盖之前已经导出的文件。
- **AI 能力全部按需开启**：画面观察、语音合成、本地语音转写、精确字幕对齐和素材检索都可以按需要单独配置。做纯文字卡片、保存项目、查看历史交付或导出做好的视频，完全不需要模型或 API Key。
- **源码交付与平台说明**：LightWeaver 通过源码工作区交付，接收方可以让 WorkBuddy 帮忙准备本机环境。macOS 目前仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac，且完整本地模型功能要求 macOS 14 或更新版本。各平台与功能的实测范围见[桌面客户端验收](docs/acceptance-desktop.md)。

## 从源码启动

请先准备 Node.js 22.13 及以上的 22.x 版本，或 24.x。在项目根目录首次安装依赖：

```sh
npm ci
```

安装完成后，按你的系统选择启动方式：

- macOS：双击根目录的 `start.command`。
- Windows：双击根目录的 `start.cmd`。
- Linux：在终端运行 `./start.sh`。
- 命令行启动：在项目根目录运行 `npm start`（或 `make desktop`）。

启动后会打开桌面窗口，在窗口里就可以新建或打开项目。如果是交给 WorkBuddy 部署和启动，可以直接发送下面这段提示：

> 阅读本工作区的 README.md 和 docs/development.md，准备所需环境，按 lockfile 安装依赖，按我选择的功能配置模型，执行 doctor 检查，然后用 npm start 启动 LightWeaver。

需要把源码打包分享给别人时，运行 `make source-zip` 生成 `out/LightWeaver-source.zip`。压缩包只包含已提交到 Git 的源码和 `.agents/skills/`，不会带入你的本地私有配置、项目数据、模型文件、Python 环境或 `node_modules`。

## 配置所需能力

需要用到 AI 功能时，可以在 **设置 → 模型与供应商** 中按需配置：

- **云端画面观察与配音**：打开 **供应商 → ModelBest → 配置**，填入 API Key 并点击 **保存密钥**。保存后立即生效，无需重启；如果系统里也设了环境变量，桌面设置里保存的密钥会优先使用。所有私有密钥只保存在本地的 `config.local.yaml` 中（已被 Git 忽略，不会随源码提交或打包）。默认使用 `MiniCPM-V-4.7-35B-A3B` 观察画面、`VoxCPM2` 合成语音。
- **本地转写、精确字幕与检索**：在 **本地模型** 中选中需要的功能模型，点击 **管理模型**，按页面状态点击 **下载并启用** 或 **启用**（如果在桌面端本机已有权重，也可以用 **选择文件** / **选择目录** 直接选用）。应用会自动安装缺少的运行组件并校验模型文件，不需要手动填写运行库或 Python 路径。

本地模型推理、语音合成和项目交接共用一套 Python 环境（可由 WorkBuddy 提前通过命令行准备，或在启用本地模型时自动安装）。

项目支持导出 MP4 视频、LightWeaver 项目包、OTIO 时间线和剪映草稿。保存与恢复、数据存放目录、CLI 输出和故障排查见[用户指南](docs/user-guide.md)。

# LightWeaver Studio

运行 `make studio` 启动浏览器版编辑界面，然后打开 `http://127.0.0.1:5175/`（桌面窗口内使用的也是同一套 Studio 界面）。

## 主要页面与工作流

左侧导航按日常创作流程分成三组：

- **创作区（项目）**：
  - 在首页可以打开已有项目、导入项目包（**打开已有项目包…**），也可以点击 **打开示例** 体验三卡片短片，或填写片名并选择工作流后 **创建空白草稿**。
  - 进入项目后，工作区分为 **画面**、**字幕**、**声音**、**方案**、**交付** 五个标签页：
    - 在 **画面** 页的左侧 **创作资源** 中导入 **素材** 或运行 **证据** 分析与候选检索，在右侧 **属性检视器** 编辑当前场景的文案、选段、时长、声音与遮罩，在底部 **故事板** 调整顺序或增删场景。
    - 在 **字幕**、**声音** 和 **方案** 页分别编辑多语言字幕与翻译、逐场旁白/原声和全片背景音乐，以及审核/采用创作方案。
    - 点击右上角 **保存** 会把当前编辑写入新的项目版本；点击 **保存并制作**（或 **制作** / **重新制作**）会先确保保存当前内容，再提交渲染任务。
- **资产与预设（方法 / 音色 / 素材库）**：
  - **音色**：支持上传参考音频并自动转写或填写 **参考文本**，也支持输入声音描述和试听文案后点击 **生成试听**，满意后点击 **保存为新音色**。
  - **方法** 与 **素材库**：每次保存都会生成带版本摘要的新版本，项目只会绑定你明确选用的那一版，之后修改或删除库里的记录不会暗中改掉已有项目。
- **系统与运维（任务 / 设置）**：
  - **任务**：按 **全部**、**运行中**、**可恢复**、**已完成** 筛选作业，查看各步骤执行详情，支持对进行中的任务点击 **取消**，或对未完成任务点击 **继续任务**。
  - **设置**：包含 **模型与供应商**（配置云端 API Key、管理与下载本地模型）、**存储**（查看数据/模型/日志目录，桌面端可更换工作区并重启）和 **诊断与修复**（检查与修复本地运行组件、查看环境信息）。

## 多端协作与交付管理

- **CLI 与 Studio 同时编辑**：如果另一个进程（例如外部 agent 通过 CLI）先更新了项目，Studio 不会直接覆盖你正在编辑的草稿，而是弹出提示条让你点击 **查看差异** 对照 **我的本地草稿** 与 **服务器当前内容**，或者点击 **保留我的草稿并加载服务器内容**，先把未保存草稿存成可恢复备份再载入最新版本。
- **交付与历史**：在 **交付** 页的 **交付与历史** 列表中，成片会按状态清晰分组为 **当前**、**内容已更新**、**历史** 和 **缺失**。你可以展开 **预览与场景定位** 直接跳转播放各场景、下载字幕/音频等 **附加文件**，也可以把选中的可用成片导出为 MP4 视频、OTIO 时间线、剪映草稿或完整项目包。

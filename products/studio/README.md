# LightWeaver Studio

运行 `make studio`，打开 `http://127.0.0.1:5175/`。先创建草稿，导入任务素材，在片子页编辑脚本、选段、字幕、声音和输出。保存生成新修订，制作按钮提交共享作业。

CLI 与 Studio 可以同时编辑。冲突页保留本地未提交内容，显示服务器当前修订。作业页支持取消和恢复未完成步骤，复盘页区分当前、过期与历史交付。

音色页支持参考音频上传、参考文本转写、设计试听、收下与删除。素材和方法页管理不可变版本，项目绑定选定版本。

配置和命令见仓库 `README.md` 与 `docs/conventions.md`。

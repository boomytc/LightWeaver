# LightWeaver Studio

运行 `make studio`，打开 `http://127.0.0.1:5175/`。先创建草稿，导入任务素材，在项目工作区编辑场景、选段、字幕、声音和交付规格。保存生成新修订，制作按钮提交共享作业。

CLI 与 Studio 可以同时编辑。冲突页保留本地未提交内容，显示服务器当前修订。任务页支持取消和恢复未完成步骤，交付页区分当前、已过期、历史和缺失交付。

音色页支持参考音频上传、参考文本转写、设计试听、收下与删除。素材和方法页管理不可变版本，项目绑定选定版本。

界面操作与模型配置见[用户指南](../../docs/user-guide.md)。源码启动与构建见[开发指南](../../docs/development.md)，CLI 与运行合同见[命令与配置参考](../../docs/conventions.md)。

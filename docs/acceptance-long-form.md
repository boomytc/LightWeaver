# 2026-10-31 连续影视素材与编辑验收

本轮把长项目的字幕保真、编辑恢复和作业回收作为工程验收目标。供应商适配、AI 配乐与音效生成继续暂缓。按当前选择，VAD、ASR 与强制对齐使用本地模块，VLM、TTS 使用 API。本轮使用原声制作，没有调用 VLM、TTS，也没有新增其本地适配。

## 真实素材与发现

使用现有 `ep03.mp4`，原始长度 261.16 秒，包含连续影视对白与原声。源文件保留原位，导入和运行状态放在系统临时目录。它是四分多钟素材，不是电影级长度或吞吐测试。

TEN VAD 与 Qwen3 ASR 按 40 秒窗口、2 秒重叠处理全片，实际生成 103 条证据。旧采用逻辑仅保留 95 条，其中完整丢掉“我就要跟苏家大小姐订婚。”以及 190 秒起的一条长句。现在仅去重同源、同说话人、相同显示原文的重叠证据，103 条完整采用。不同内容即使重叠也保留供作者核对，分析证据不改写。否定句、不同标点、不同说话人、不同 sourceText 与相接区间也完成临时验收。

首窗实际强制对齐返回“心”字 14.56 至 14.56 秒，导致空句界失败。严格拒绝保留，没有伪造 aligned。后续工程制作显式使用 estimated；人工编辑的句子改为 manual。全片精确字幕质量未通过验收。

后续已定位到 ASR 上下文过碎和固定窗口截断话语的问题。修复后，同一份全片完成实际强制对齐与 precise 制作，详见[全片精确对齐根因与验收](acceptance-alignment-root-cause.md)。本节保留当时的失败和 estimated/manual 验收记录。

## Studio 修改与恢复

真实浏览器完成重新采用、检索“订婚”、清空后重写、修改源入点与时长、按 ID 移除旧重复句、保存修订。数据库确认 102 条 cue 保留，校对句的范围为 150.746 至 155.110 秒，原始 sourceText 未改变，质量为 manual。

每页只挂载 25 个 cue 编辑器。实机检查从原先 101 个编辑器与 video 元素降为当前页 25 个；这只证明挂载范围，未量化输入或滚动速度。检索覆盖字幕、原文与说话人。重叠筛选比较同一时间轴、源版本或场景语音时间钟，不把相接区间标成重叠。不同钟之间的最终重叠仍需制作后复盘。

浏览器尝试刷新时触发离页保护并持久保存未提交草稿。另开同项目页面，显式恢复了尚未保存的说话人字段，原 revision 基线保留，服务器未被自动覆盖；随后保存成功。备份可显式清除。该验收不代表多用户协同、浏览器存储禁用或配额耗尽时仍能保证本地持久化；写入失败会显示错误，并保留复制入口。

作业详情按 project/run 与请求序号接受响应，切换时清空旧详情。恢复与取消按钮受提交状态约束；恢复和 brief 请求返回后检查项目代次。辅助作业提交、取消、恢复与轮询终态会同步项目作业列表。实际 MOSS 全片分段返回 43 条带临时说话人的 cue，未采用覆盖字幕；全局列表同步显示成功。另一段 60 秒素材通过面板取消并恢复同一 run，恢复后模型返回 40.01 秒的越界句尾而被拒绝，面板与全局作业页同步显示失败和恢复按钮。没有放宽时码验证来得到成功状态。

九段原声场景覆盖整段 261.16 秒素材。最终交付为 360×640、30fps、7,835 帧，时间轴长度 261.166667 秒，计划音频 12,536,000 个 48kHz 样本；实际解码 12,536,832，832 个 padding 在 2048 上限内。收据记录 estimated/manual，estimatedTiming 为 true。提取成片 153 秒画面确认中文字幕可读，源片已烧录的外文字幕保留。

在新运行器上实际渲染中取消，再恢复同一作业。probe 与 compile 的 attempt 均保持 1，render 从 1 增至 2，取消期间上一份交付仍保留，恢复后发布新 current 交付。

OTIO 官方库生成后重载成功。OTIO 与剪映包完整性检查均通过，移动媒体引用可解析。旧剪映导出因重叠字幕报 SegmentOverlap；现在分配独立文本轨，文字与时码保留。bundle 导入新项目后，102 条 cue 的标识、正文、sourceText、源范围与说话人完全一致。本轮没有实际打开剪映应用，重叠轨的编辑器排版仍需人工核对。

## 进程与审查

隔离复现了 31 分钟 attempt 误报 CANCELLED。修复后返回 DEADLINE_EXCEEDED；用户取消仍为 cancelled，worker 停止为 interrupted。挂起的 ffprobe、卡片 describe、fontconfig 探测均能接收节点取消，且没有残留 PID。

原 worker 被 SIGKILL 后子孙进程仍存活。现在独立监督进程通过 stdin EOF 或 IPC 断连回收目标组，三秒后升级 SIGKILL。主代理再次实测，拒绝 SIGTERM 的子进程、孙进程与监督者均退出。正常输出、非零退出、缺失命令、超时、取消、参数原样传递和跨 chunk 中文解码通过有限验收。36 MiB 中文输出的旧实现错误返回成功，现在按字节执行 32 MiB 上限，超限后排空并丢弃后续输出，返回 OUTPUT_TOO_LARGE。

Model the Domain 用于区分取消、超时与输出溢出，以及独立的 IPC 消息合同；Prove It Works 用于实际媒体、浏览器、数据库和进程组验收。独立审查分别覆盖 Studio 与媒体、作业生命周期。审查发现的辅助作业终态刷新和输出限额问题已在对应边界修复。当前差异按 simplify-code changed 与 simplify-test changed 范围审查，没有新增或删除永久测试。测试价值参考已读取，临时验收资产按本仓约定清理；生产诊断、schema、边界与类型检查保留。

`npm run typecheck`、Studio 构建、Python AST、监督脚本语法与 `git diff --check` 通过。构建保留既有 Zod 的 Rollup 注释提示。临时状态、脚本、媒体、浏览器备份与验收服务在交付前清理；原始媒体、已有模型环境与本地配置保留。

真实用户仍需评价转写准确度、镜头选择、节奏、声音观感和连续审片效率。本轮没有给出模型质量排名，也没有证明小时级、4K、多用户或所有第三方编辑器的制作体验。

# 功能收尾验收

日期：2026-11-01。环境：macOS Apple Silicon，源码工作区和本机未签名桌面包。

本次完成外部 agent 通过 Skill 创作、Studio 编辑同一项目修订、制作和最终交付之间的剩余缺口。以下证据支持当前约定功能范围开发完成；模型效果、长片创作质量和未实测平台仍按各自验收记录说明。

## 收尾结果

| 缺口 | 实现与可观察结果 |
| --- | --- |
| 取消旁白后遗留 speech 字幕 | 共享场景引用规则在删除场景、取消旁白、改用原声或静音时清理已有 speech 字幕。独立 timeline、source 字幕保留；新写入的无效引用在保存边界拒绝。源码桌面取消卡片旁白后保存，关联字幕移除，随后实际制作成功。 |
| 审核计划与实际制作修订不一致 | 共享提交入口、HTTP 和 CLI 均要求 `expectedRevision`；Skill、项目 brief、教程和 `make films` 携带审核修订。实测缺少修订被拒绝，旧修订与新 head 冲突，同一制作请求返回原作业。 |
| 导入冲突没有恢复入口 | Studio 保留结构化错误，显示差异与草稿恢复入口。外部 CLI 推进标题后，从旧修订导入素材，界面出现冲突，备份草稿并载入新标题。 |
| bundle 遗漏待采用方案的 TTS 缓存 | 收集范围覆盖当前场景及 CreativePlan 场景，并继续核对文字、语言、音色版本和样式。临时夹具确认相关缓存与字节进入 bundle，无关缓存排除，导入后引用完整。 |
| 配置写入无法安全重试 | 配置和不含明文密钥的请求收据一起原子替换。CLI 保存、供应商采用及已有模型采用重放首次结果；后续配置推进不改变原请求结果。参数改变复用 requestId 被拒绝。模型采用重放不再依赖原模型文件仍存在。 |
| 导出响应丢失后无法确认结果 | 视频、bundle、OTIO、剪映使用同一持久化导出服务。首次请求固定交付或项目修订，排他发布，并以目标身份及内容校验重放。跨进程重试、目标篡改拒绝、文件与目录发布后中断恢复均通过。 |
| 卡片命令帮助与合同不符 | `scene add` 帮助明确 label 默认取标题、body 可省略，与运行合同一致。 |

独立复审还发现并修复了批量导入的部分成功重试问题。真实桌面中，第一项收到成功响应、第二项已入库但两次响应丢失；重选整批后复用原请求，提示导入完成，素材总数和项目修订均没有再次增加。返回旧结果不会将本地基线退回先前修订。

## 实际链路

源码验收从 CreativePlan 导入与显式采用开始，经视频和音频导入、混合卡片与视频场景、字幕及遮罩、审核计划、制作、桌面编辑，最终导出成片。桌面取消旁白后的成片由 ffprobe 核对为 640×360、30 fps、90 帧、3 秒，视频为 H.264，音轨为 AAC；分别抽取卡片和视频段的成片帧，确认两类场景的红色遮罩均生效。

桌面导出在后端完成发布后故意丢弃首次响应，自动重试携带相同 requestId 和 deliveryId，最终显示成功并得到有效 MP4。运行时配置保存同样在首次响应丢失后恢复原请求。此次桌面验收未记录未捕获的页面异常。

CLI 对 MP4、bundle ZIP、bundle 目录、OTIO 和剪映目录分别执行首次导出与跨进程重放。相同请求返回首次结果；改用不同参数或篡改目标会被拒绝。OTIO、剪映包通过产品的 `export verify`。不提供 FFmpeg、ffprobe 或模型 Python 时，项目 context 和已有 MP4 导出仍成功，副本摘要一致。

恢复验收在临时进程中实际中断执行：文件或目录已经发布、数据库尚未确认时终止进程，原请求可以恢复；准备阶段中断并推进项目 head 后，bundle 仍使用首次固定的修订。相同请求并发执行会合并或报告可重试的执行中状态，不重复发布。成功恢复后清理本次暂存目录。

## 随包运行

重新构建本机桌面包，资源清单与运行时查询通过。在 `PATH=/usr/bin:/bin`、不提供宿主工具覆盖的独立数据目录下，通过随包 CLI 创建并修改示例，审核修订后完成制作、MP4 导出、bundle 目录导出与重放，证明使用随包 Node、媒体工具和交接 Python。

随后启动同一桌面包，打开该 CLI 项目、读取当前交付并实际播放。媒体元素解码到 640×360、3 秒，未报告媒体错误；生产运行时工具检查全部就绪，未记录未捕获的页面异常。退出应用后，本次 Electron 及所属服务均结束。

## 检查与边界

- TypeScript 与公开模块边界检查通过；Studio 生产构建及本机桌面打包通过。构建仍有依赖注释和 chunk 大小提示，不阻断产物。
- 三个项目 Skill 通过结构校验。调用步骤与当前命令元数据核对，制作提交固定审核修订，重试保留原请求参数。
- 夹具、故障注入脚本和合成媒体仅用于有限验收，未作为测试资产加入仓库；用户项目、媒体和模型不参与此次故障注入。
- 本次不调用真实 VLM、TTS、ASR、对齐或检索模型。既有模型证据见[模型安装验收](acceptance-model-setup.md)、[架构升级验收](acceptance-v2.md)和[强制对齐与检索验收](acceptance-alignment-search.md)。
- 本次运行证明限于 macOS Apple Silicon。Windows、Linux、Intel Mac 的真实安装与运行，以及未签名包的签名、公证和发布，不在此次完成结论中。
- OTIO、剪映包的结构与完整性验证不等于在所有外部编辑器版本中实测。真实长片的表达质量与编辑体验仍需实际项目和用户反馈。

此前功能与恢复证据见[Agent 制作与交付验收](acceptance-agent-delivery.md)、[桌面客户端验收](acceptance-desktop.md)和[编辑与恢复验收](acceptance-editing-recovery.md)。

# 配置分层与凭证验收

日期：2026-11-02。环境：macOS Apple Silicon，源码 HTTP 服务和本机未签名桌面包。

## 当前合同

模型和供应商配置通过同一读取器解析，顺序为私有 `config.local.yaml`、环境变量、内置 `config.yaml`；空字符串和纯空白视为未设置。平台相关的 Python 缺省路径仍由共享平台逻辑计算。显式 CLI 或请求参数的含义不变。

`config.yaml` 替代原配置示例并实际参与读取，源码读取仓库根文件，桌面包读取资源目录中的同名文件。私有配置仍由 `runtime.configFile` 指定，设置页只写私有覆盖，不修改默认文件。API Key 默认留空，现有用户配置不迁移、不覆盖。

## 验收结果

| 路径 | 证据 |
| --- | --- |
| 设置保存到实际请求 | 隔离 HTTP 服务中预置旧环境变量，通过设置页使用的 PUT 接口保存新凭证。随后实际 Providers 请求本机接收端，Authorization、端点和型号均来自本地配置，无需重启。 |
| 清除与空值 | 清除本地凭证后，下一次请求使用环境变量；本地与环境值均空白时，采用默认文件或标为未配置。无凭证时明确拒绝请求。 |
| 来源一致 | 设置返回的 file、environment、default、unset 与实际凭证、型号、端点选择一致。ModelBest 和 DeepSeek 均验证本地凭证优先。 |
| 本地运行时 | 对齐、视觉、说话人及语音适配器采用本地解释器路径，覆盖环境变量。只检查路径选择，不执行这些模型。 |
| 默认下载目录 | 内置配置声明 models；源码 CLI、浏览器服务和源码桌面运行时均解析到 monorepo 根目录下的 models，与私有配置位置和启动目录无关。正式包沿用用户模型目录；显式本地和环境变量路径仍按 configBase 解析。 |
| 空白下载目录 | 模型下载目录环境变量仅含空白时，源码模式使用 monorepo 的 models，不创建空白名称目录。 |
| 默认文件 | 独立资源目录中修改默认型号后，后续读取使用新值；缺少默认文件时返回 CONFIG_MISSING。 |
| 保存与重试 | 原配置请求在后续修订推进后仍返回首次结果。私有文件权限为 0600，请求收据不含明文凭证。 |
| 桌面包 | 重新打包并通过资源清单与运行时校验。包内 config.yaml 与源码文件字节一致，属于必需资源。 |
| 随包 CLI | 在仓库外、PATH 仅含系统目录的环境中，验证本地覆盖环境、清除后回退、环境缺失时使用包内默认值，以及配置写入重放。默认 VLM 仍为 ModelBest 的 MiniCPM-V-4.7-35B-A3B。 |

公开模块边界和 TypeScript 检查、Studio 生产构建、本机桌面打包及文档链接检查通过。构建保留已有依赖注释与 chunk 大小提示。

## 范围

凭证请求使用自建回环接收端，证明选择和发送链路；本次未访问真实供应商，也未执行付费推理或本地模型。桌面设置的业务验证通过它实际使用的 HTTP 接口完成，未重复进行原生界面交互验收。Windows、Linux、Intel Mac 未做实机验收。

临时脚本、隔离配置与数据库在验收后清理，不保留测试资产。现行优先级以本记录和[命令与配置参考](conventions.md)为准；旧验收中的环境变量覆盖描述仅记录当时行为。

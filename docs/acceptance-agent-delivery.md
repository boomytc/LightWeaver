# Agent 制作与交付验收

2026-11-01，基线 `ea5bd81`。范围为桌面与 CLI 的视频交付、素材来源、项目技能及其发现入口。所有验收项目、脚本、片段和输出放系统临时目录；用户正在编辑的短剧项目、草稿和原始媒体保留。

## 实现

- CLI `export --format video` 与桌面按钮共用核心导出。默认 current，显式 delivery 可选完整的 stale 或 historical；结果包含交付身份和状态。复制前后校验摘要，在目标目录独立暂存并排他发布，不覆盖已有文件。目标文件系统必须支持链接发布，不支持时返回明确错误。
- `capabilities`、`doctor` 返回实际运行模式、数据、配置及资源路径。capabilities 提供配套技能路径。三个技能迁到 `.agents/skills`，随桌面资源一并提供。桌面项目使用随包入口，源码模式显式核对工作区。
- 可选 provenance 进入不可变素材版本，包含处理说明、精确来源、用途、源窗和素材字幕状态。CLI、路径 HTTP 和 multipart 导入均可记录。导入前拒绝项目外来源、非音视频时间窗和越界范围。
- 项目读取、修订 pin、构建快照和 bundle 包含来源依赖闭包；导入缺少依赖的包被拒绝。交接原始素材元数据也保留这些字段。素材区和场景属性显示来源与内嵌字幕说明。旧素材无记录时保持未知，不推断来源或重写旧项目。
- `artifact show` 通过公开 app 入口读取 manifest、receipt 等 JSON，验证摘要并拒绝非 JSON 媒体。历史修订使用 `project show <project-id> --revision <revision-id>`。

## 实际验收

使用用户提供的六份原片及两份参考，各提取前 20 秒。主路径以短参考为画面匹配输入，在六份原片竞争中返回原片 1；纯视觉 method 和缺少转写的 warning 保留。采用候选的 0–20 秒，并分别绑定原片画面、参考音轨和独立人工字幕。人工字幕使用明确的验收文字，不作为真实对白或模型质量证据。

实际制作得到 360×640、30 fps、600 帧的 20 秒 H.264/AAC 成片。CLI 导出摘要与视频 blob 一致，FFmpeg 全片解码成功。修改独立字幕后再次制作，旧交付成为 historical；显式导出旧交付保持原摘要。bundle 换数据根导入后，字幕、来源及素材依赖保持一致，并可再次制作与导出。

失败边界实际覆盖已有文件、指向已有文件的软链、并发同目标导出、损坏的交付、隐式选择 stale、非法来源和越界来源。既有文件保持原字节；并发调用只有一个发布成功；失败不留下最终视频。保留 derived 单项而移除显式祖先列表后，项目仍能读取全部来源；删除包中的来源版本则在导入前被拒绝。

Studio 生产构建在独立本地服务中实际打开。素材与场景属性均显示处理说明和来源；切回原片后可继续编辑。字幕页修改、保存和恢复正文后，服务端修订确认一致。通过页面导出视频，文件摘要与当前交付相同，控制台未见错误。HTTP multipart 和路径导入都保留 provenance；非法 JSON 来源被拒绝且不增加修订。

独立 agent 仅获得真实导出请求、技能和验收工作区入口，完成 MP4 导出、完整解码及摘要核对，正确区分项目内独立字幕与视频中烧录的字幕，并报告预处理来源及适用范围。该轮暴露的 JSON 产物读取入口缺失已由 `artifact show` 补齐。

`artifact show` 实际读取 manifest、receipt，通过公开历史修订入口读取对应项目内容；视频等非 JSON 媒体和摘要损坏的 JSON 被拒绝。最终包的随包 CLI 在仅系统 PATH 下完成技能路径发现、JSON 读取及显式交付导出，摘要一致。新包使用隔离用户目录真实启动，项目列表、项目打开和素材页显示正常，随后正常退出。

三个技能通过 frontmatter 校验、相对引用检查；工作区类型与公开边界检查、Studio 构建通过。桌面资源包含三个技能与配套合同说明，macOS arm64 资源摘要和运行时校验通过。复审限定 simplify-code changed、simplify-test changed，保留现有产品诊断、schema 和边界检查，没有增加常驻测试或测试专用产品入口。

## 验证范围

本轮验证短片工程与交付链，没有调用模型 API、下载权重、执行 ASR/强制对齐或验证完整 9 分钟参考片的逐镜头一致性。多参考剪辑差异、选材理由和字幕编辑边界已写进技能，创作正确性仍由作者审查。Windows、Linux 和 macOS Intel 未做本轮实机验收。应用包未签名、公证。

纠错主要落在第一层的共享导出接口、素材版本合同与依赖闭包。多参考用途、精确复刻的主张和用户交付偏好需要创作判断，保留在技能中。

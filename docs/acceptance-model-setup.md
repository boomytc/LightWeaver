- ModelBest 预设为 `MiniCPM-V-4.7-35B-A3B`、`VoxCPM2`，提供平台与文档跳转；保存密钥和采用预设为独立动作。

- 下载沿用 Jobs，支持取消、重试和完整文件复用；独立暂存、校验后发布，不覆盖内容冲突的原件。下载不会自动采用配置。
- 可指定下载根目录或采用已有文件/目录。采用前校验全部必需文件。文本与视觉检索共用 EmbeddingGemma 2 权重和运行时。
- 新配置的强制对齐默认 Torch CPU，MLX 仅显式选择。既有配置不会被自动迁移。

## 2026-11-02 强制对齐统一为 Torch

强制对齐现在只通过 `qwen-asr` 的 `Qwen3ForcedAligner` 加载官方权重，结果合同固定为 `qwen3-torch`。配置合同、模型采用绑定和桌面环境变量清单已移除后端选择，MLX 执行分支及独立依赖清单一并删除。CPU 为默认设备，显式 CUDA 设备配置保留。

隔离配置保留旧 `alignment_backend: mlx`，同时设置旧后端环境变量，正式 Providers 入口仍只检查 Torch 依赖并成功执行对齐。2.6406875 秒中文合成语音“今天我们一起去公园散步。”返回 11 个字时间和一条原文字幕，原文覆盖与时码校验通过。环境为 Apple Silicon、`qwen-asr==0.0.6`、`torch==2.15.0`、Transformers 4.57.6，实际使用 CPU。

官方权重采用前通过完整大小与 SHA-256 校验。采用后不写入后端配置，原有旧配置行和无关行保留，旧配置行不参与执行。设置 API 拒绝已移除的 `alignmentBackend` 字段；运行时依赖接口只提供三份当前清单，旧 MLX 清单下载返回 400。用户原配置摘要在验收前后相同。

`npm run typecheck`、Python AST、脚本语法检查与 macOS arm64 完整打包通过，最终包资源及运行时查询校验通过。本轮未重跑全片制作，也未验证 Windows、Linux 或 CUDA 推理。

## 2026-11-02 模型状态与主操作

模型详情按当前状态提供操作，已启用模型不再显示准备按钮，已下载文件显示“启用”，已配置但缺组件时显示“准备运行组件”，路径或文件异常时显示检查入口。高级区保留校验和已有路径采用，移除重复下载按钮。

共享准备计划区分当前配置、下载目录已有文件和需要下载三种来源。已有文件不创建模型下载节点；采用当前模型时保留路径与设备等模型绑定，启用前核对冻结的配置和文件快照并完成 SHA-256 校验。

- 隔离作业实际完成当前模型启用、单独补齐 TEN VAD 和已下载模型启用，均未创建模型下载节点。当前模型路径保留，下载根目录没有新增权重副本；全部外部下载请求在验收进程中被拒绝，实际尝试次数为零。
- 缺文件时仍创建下载节点，执行前取消不会写配置。与清单大小相同但内容损坏的已有文件校验失败，不启用；提交后更换模型路径会拒绝旧快照，保留新配置。同一请求重放返回原作业。
- 旧作业没有来源字段时仍按原下载目录完成启用。另模拟旧作业已写入配置、尚未登记节点结果就中断，恢复重放原配置收据成功，没有改写配置或产生请求身份冲突。
- Studio 实际点击通过“准备运行组件 → 已启用”和“启用 → 已启用”，完成后准备按钮消失。异常路径显示“检查配置”，点击后展开文件诊断；这些页面的普通区和高级区均无下载按钮，控制台错误与警告为零。
- 临时延迟目录状态刷新，在已有文件目录与空目录间双向切换，主操作仍在旧元数据返回前正确切换为“启用”或“下载并启用”，不会沿用上一个目录的按钮文案。
- 页面提交已展示的文件来源作为前置条件。规划后移走已配置或已下载文件时，准备请求在创建作业前失败；HTTP 实测返回 409 / MODEL_FILES_CHANGED，没有新作业、配置写入或模型下载。同一请求重放保持原作业，更换来源复用请求标识会被拒绝。
- 最终 macOS arm64 包内 CLI 在仅含系统目录的 PATH 下启用已配置模型成功，作业只有启用节点，保留原路径且未创建权重副本。全工作区类型检查、Studio 构建、完整打包和最终资源校验通过。

本轮使用已有 ASR 权重的硬链接和隔离配置验证文件复用，没有重新下载大模型或执行推理；未实测其它平台。临时数据、脚本、页面和服务在验收后清理，用户原配置和模型字节保持不变。

## 交付范围

- ModelBest 预设为 `MiniCPM-V-4.7-35B-A3B`、`VoxCPM2`，提供平台与文档跳转；保存密钥和采用预设为独立动作。
- 本地清单为 Qwen3-ASR Q8 GGUF、TEN VAD、官方 Torch Qwen3-ForcedAligner-0.6B、EmbeddingGemma 2 GGUF 与 mmproj；固定来源 revision、文件大小和 SHA-256。独立重排、说话人区分不列入预设。
- 下载沿用 Jobs，支持取消、重试和完整文件复用；独立暂存、校验后发布，不覆盖内容冲突的原件。下载不会自动采用配置。
- 可指定下载根目录或采用已有文件/目录。采用前校验全部必需文件。文本与视觉检索共用 EmbeddingGemma 2 权重和运行时。
- 新配置的强制对齐默认 Torch CPU，MLX 仅显式选择。既有配置不会被自动迁移。

## 实际验收

- Weaver、Studio 类型检查及 Studio 生产构建通过；接口边界检查与 `git diff --check` 通过。
- CLI 真实下载 TEN VAD：744600 字节，SHA-256 为 `81b2de13710670bb94fef315ab50fedc903a21c04c4290c6c2ac28d8b42e715a`。重复执行禁用网络仍复用完整文件。
- 本机已有 ASR、EmbeddingGemma 主干和 mmproj、官方 ForcedAligner 全部必需文件通过清单校验；单文件任意文件名及多文件目录采用均通过。相同大小但字节损坏的 TEN 文件在写配置前被拒绝；目标冲突保留原件。
- 隔离配置实测：不回显已有密钥，空密钥不覆盖旧值，保留无关行，拒绝控制字符，revision 冲突无写入，新建锁不被抢占，配置权限为 `0600`。实际 HTTP 过期 revision 返回 409，用户配置摘要未变。
- Studio 真实操作通过：ModelBest 获取入口和空密码框、未保存下载根目录预览、TEN 下载完成与 SHA 校验、已有外部路径的采用入口、ASR 取消→同作业重试→再次取消。修复将 SSE 当 JSON 读取导致完成状态不更新的问题，订阅与轮询在终态或离开页面回收。
- 用隔离配置服务和临时作业事件夹具复验：环境变量覆盖下载根目录后，输入值与文件状态一致；切换作业不沿用上一作业的进度；下载目录自动填入的采用路径可直接使用。目录刷新拒绝晚到的旧路径响应，进度按事件 `runId` 归属。
- CLI 真实 TEN VAD + Qwen3-ASR GGUF 作业一次成功，4.20 秒中文语音转写为“甚至出现交易几乎停滞的情况。”，VAD 检出 0.330–3.958 秒；ASR 时间质量标为 `estimated`，精确时间由对齐产生。
- 官方 `qwen-asr==0.0.6`、Torch CPU 通过真实产品对齐脚本处理 4.20 秒中文语音，13 字全部返回时间，范围 0.40–3.68 秒。使用独立临时 Python 环境，不借用相邻项目运行时。
- 文本检索走实际 Providers 冻结绑定与嵌入接口：查询、相关和无关文本均为归一化 768 维，相关相似度 0.8034，高于无关 0.6269。
- 视觉检索走实际 VisualModels 冻结绑定与接口：公交车查询对公交图相似度 0.6975，高于鸟图 0.5916，均为 768 维。样例只证明路径和基本语义成立。
- 共享可执行文件解析器的临时检查覆盖两种目录分隔符、相对仓库路径、PATH、缺失文件及各平台 Python 默认路径；配置示例不再将 Unix 路径强制套给 Windows。

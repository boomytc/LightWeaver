# 2026-10-31 强制对齐与检索验收

> 后续模型调整：文本语义检索已改为与视觉检索共用 EmbeddingGemma 2 主干和 mmproj，旧 Qwen3 Embedding 默认路径已移除。本文中的 Qwen3 Embedding 结果保留为当时验收记录，不能代表当前缓存或运行绑定。当前范围见[模型预设与本地安装验收](acceptance-model-setup.md)。

本次接入 Qwen3 强制对齐、文本向量检索和可选候选重排。参考 LightASR 的语种、原文与真实时间戳处理，以及 AutoModel 的 GGUF pooling、查询指令和重排调用方式。适配代码、Python 环境和作业生命周期由 LightWeaver 管理，运行时不导入相邻项目。权重和 `llama-server` 使用显式配置路径。

## 实测环境

本机为 Apple Silicon。模型 Python 为本仓 `weaver/.venv` 的 Python 3.12.13，安装 mlx-audio 0.6.3、MLX 0.32.4、NumPy 2.5.4、Transformers 5.22.1 和 Tokenizers 0.23.3。`llama-server` 为 0.6.0，build 11429，commit d81235049。

实际加载的模型如下：

| 能力 | 权重 | 运行方式 |
| --- | --- | --- |
| 强制对齐 | Qwen3-ForcedAligner-0.6B-8bit | MLX |
| 向量检索 | Qwen3-Embedding-0.6B-Q8_0.gguf | llama-server，last pooling，L2 归一化 |
| 候选重排 | Qwen3-Reranker-0.6B-fixed-Q8_0.gguf | llama-server，rank pooling |

Embedding 权重来自 Qwen 官方 GGUF 仓库，其余使用本机已有权重。模型路径、Python 环境和本地配置均被 Git 忽略；凭据未进入代码或记录。本轮没有调用远端模型。

## 强制对齐与成片

系统语音分别生成三句中文，再以一秒静音连接，得到 10.1883125 秒音频。真实 MLX 对齐返回 28 个字时间和三段原文。通过公开 Application 入口导入音频和合成源片，以 `precise` 字幕完成真实构建，得到 320×180、30fps、306 帧的视频。

时间轴与 SRT 使用相同句界，帧量化结果如下：

| 作者原文 | 起点，秒 | 终点，秒 |
| --- | --- | --- |
| 红色的汽车正在路上行驶。 | 0 | 2.566667 |
| 一只小狗坐在草地上。 | 3.666667 | 5.833333 |
| 厨师正在厨房切菜。 | 7.033333 | 9.033333 |

交付登记为 `current`，三段字幕均记录为 `aligned`。对照各句独立语音文件的拼接边界，六个边界的最大差为 199.1ms。该参考包含合成语音尾部静音和帧量化，只证明此构造样例的链路与句界结果，未进行人工真实语音精度评测。

缺少对齐权重时，自动精确字幕在创建作业前返回 `CONFIG_MISSING`。同一场景提供人工语音 cue 后，即使模型仍缺失也可完成构建，保留 `manual`、第 15 帧起和 45 帧时长。原文覆盖不完整时拒绝生成精确字幕；独立前导标点能保留。

## 语义检索与重排

隔离项目导入六条人工文本证据。三个改写查询均通过真实向量模型和重排模型返回预期首项：

| 查询 | 首项 |
| --- | --- |
| 宠物在户外休息 | 一只小狗趴在草地上晒太阳。 |
| 车辆冒雨行驶 | 雨天的街道上，一辆红色轿车缓慢驶过。 |
| 做饭前处理食材 | 厨师在厨房里切番茄，准备晚餐。 |

查询和素材采用不同角色与缓存键。使用新 requestId 重复同一查询时，向量和重排全部命中缓存，没有新增模型请求事件。检索前后的源证据完全一致。素材过滤、完整证据时间窗过滤、空候选、空查询和倒序时间窗均完成有限验收。

Studio 的实际构建产物通过 HTTP 提交语义检索与候选重排，作业成功。候选页首项为小狗证据，分别显示语义分数和重排分数。分数只表示模型相关性，不表示正确率。

## 取消、恢复与绑定

实际启动 Python 和 GGUF 服务后取消检索，确认两个进程均退出，候选数量不变。显式恢复后作业成功并发布候选。

临时注入候选发布故障，推理结果收据已保存而作业失败。恢复复用原收据，没有再次请求模型，候选恰好增加一份。候选发布处于 runner 的完成事务中。

其他边界检查均通过：不支持的 `auto` 语种、超过 180 秒的对齐输入、实际超过 8192 tokens 的向量输入、缺失权重、冻结后模型字节变化、软链目标字节变化和循环软链。设置污染的 `PYTHONHOME` 与 `PYTHONPATH` 后，本仓模型依赖诊断仍可运行。运行器不继承外部 Python 导入路径。

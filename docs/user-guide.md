# 使用 LightWeaver 制作视频

用已有视频、图片和文字建立项目，在 Studio 中编辑场景、字幕和声音，再制作与导出。先完成一次素材制作，再按需要配置 AI 功能。

想先看到完整结果时，走[制作第一部短片](quickstart.md)。它使用三张内置文字卡片，不需要模型、API 密钥或自备素材。

## 打开桌面应用

如果已取得桌面包，解压后打开 LightWeaver。macOS 打开 `LightWeaver.app`，Windows 打开 `LightWeaver.exe`，Linux 打开分发的 AppImage 或解压目录中的 `LightWeaver`。

桌面包已包含普通制作和交接所需的工具。启动应用无需另行安装 Node、FFmpeg、Chrome 或交接 Python。API 密钥、本地模型权重和模型运行环境按所用功能配置。

当前桌面包未签名、未公证。本机验收覆盖 macOS Apple Silicon。其他目标的构建与验证范围见[桌面客户端验收](acceptance-desktop.md)。

如果手头只有源代码，按[源码启动步骤](../README.md#从源码启动)准备依赖，再使用仓库根目录的启动脚本。源码版制作卡片需要 FFmpeg、ffprobe 和 Chrome。构建后的桌面包包含这些普通制作工具。

## 制作第一部片子

1. 打开 **项目**，点击 **打开示例**。示例包含三张固定 3 秒的文字卡片，没有旁白。
2. 在 **画面** 中选择卡片，修改文字或属性。
3. 点击 **保存并制作**。项目已经保存时，按钮显示为 **制作**。
4. 在 **任务** 中查看进度。需要继续核对内容时，点击 **返回故事板**。
5. 制作完成后，从完成提示进入 **交付**，导出 MP4。

这条路径不需要模型、API 密钥或自备素材。详细步骤和预期结果见[制作第一部短片](quickstart.md)。

要制作自己的内容，返回 **项目** 创建草稿或导入已有项目包。草稿建立后，可导入视频或图片、添加 card、still 或 clip，并在右侧属性中设置文字、选段、时长和画面。字幕与声音按需添加。

需要批量写入场景或由 agent 协作时，阅读[场景、时长与采用](concepts.md)和[电影制作技能](../.agents/skills/lightweaver-film/SKILL.md)。场景时长、旁白超窗和方案采用都以运行时 schema 为准。

选中带来源记录的预处理素材时，素材区和场景属性会显示处理说明、原片和参考来源。已嵌入素材画面的字幕不能在字幕页逐句修改；字幕页编辑独立字幕轨。外部 agent 应在导入预处理素材时记录这些信息。旧项目未记录来源的素材不会自动补全。

取消场景旁白，或将视频切换为原声、静音时，绑定这段旁白的字幕会一同移除。独立时间轴字幕和源片字幕仍保留。

## 按需要配置 AI 功能

打开 **设置 → 模型与供应商**，只配置本次制作需要的能力。

### 使用画面观察和语音合成

1. 在 [ModelBest 平台](https://platform.modelbest.cn/)获取 API Key。
2. 在设置页保存 Key。
3. 点击 **采用 ModelBest 预设**。

该预设使用 MiniCPM-V-4.7-35B-A3B 观察画面，使用 VoxCPM2 合成语音。保存 Key 和采用预设是两个步骤。页面显示当前设置的来源，启动环境中的配置优先。

使用语音合成时，在 **音色** 中准备音色，再为场景选择音色并填写旁白。画面观察结果供选材参考，项目旁白由你或外部 agent 编写。API 用量与账户余额在供应商平台管理。

### 使用本地转写、精确字幕或素材检索

1. 在 **模型与供应商** 中选择对应模型，指定下载目录并下载。已有模型可选择现有路径。
2. 执行完整性校验，再采用该路径。下载完成本身不会修改模型设置。
3. 打开 **运行时与路径**，按页面说明创建独立模型环境，并指定 **模型 Python**。
4. 按所选能力补齐运行库路径。在 **诊断及应用信息** 中检查缺失项。

本地转写需要 Qwen3-ASR、TEN VAD、transcribe 运行库和 Python bindings。精确字幕需要 Qwen3-ForcedAligner。文本语义检索与画面检索共用 EmbeddingGemma 2，并需要对应的 llama-server。

权重校验通过表示文件完整。诊断就绪表示运行条件满足。实际效果以 **任务** 中的作业结果为准。安装包不会在首次启动时自动下载权重或安装模型环境。

## 保存、恢复与转交项目

点击 **保存** 会写入新的项目修订。点击 **保存并制作** 会先保存当前编辑，再制作这个修订。保存方案只生成待审方案；只有在方案页明确采用后，方案中的场景才替换或追加到当前场景。

切换项目或从应用菜单退出时，按提示处理未保存内容，可选择保存、保留草稿、放弃或取消。重新打开项目出现 **恢复草稿** 时，先恢复并核对内容，再保存。

关闭桌面窗口时，选择后台进程的处理方式：

- **后台运行**：隐藏窗口，制作和下载继续执行。点击系统托盘中的 LightWeaver 图标，或选择托盘菜单的 **打开 LightWeaver**，可返回编辑。
- **停止后台并退出**：先处理未保存草稿，再停止本地服务和正在执行的作业，退出应用。
- **取消**：保持窗口打开。

后台运行前会将编辑内容写入恢复草稿；写盘失败时窗口保持打开。后台运行期间，也可通过托盘菜单的 **退出 LightWeaver** 结束应用。

在 **交付** 中按用途导出：

- 导出成片，获得可播放的视频。
- 导出 LightWeaver bundle 项目包，转交给另一台机器或保留可再次导入的项目。
- 导出 OTIO 或剪映草稿，继续在外部编辑器精修。剪映适配目标为 macOS 11.7.0。

未选定某份交付时，视频默认导出标记为 **当前** 的交付。需要旧版本时，在对应交付上点击 **导出时使用这份**，再导出。重新制作后，核对所选交付再导出新版本。缺失或损坏的交付不能导出。导出时选择新的文件名，已有目标文件会保留。

素材导入、配置保存和导出遇到短暂网络中断时，界面会尝试恢复原请求。批量导入提示部分成功时，在当前会话重选同一批素材可继续确认，不会重复加入已确认的项。导出尚未确认时，重试需选择同一目标，并保留已写出的文件；文件被移动或修改后应选择新目标重新导出。CLI 重试还需保留原 `--request-id` 和完整参数。

修改项目后，依次 **保存 → 制作 → 导出**，获得更新后的视频。保存项目不会改写已经导出的文件。项目内的独立字幕可以继续修改，导出视频中烧录的字幕则需修改项目后重新制作。

查看项目和导出现有视频无需准备制作时的模型与媒体工具。重新制作时，再检查当前环境和所需能力。

导入 bundle 时，回到项目首页选择项目包 ZIP 或完整目录。导入会创建独立项目。

更换电脑或重装前，保留项目包和原始素材。模型文件与供应商密钥需要在新环境中另行配置。

## 查找数据与排除故障

在 **设置 → 存储位置** 查看当前数据目录。更换目录会重启本地服务，原目录保留。桌面应用的数据默认位于系统用户配置目录中的 `LightWeaver/weaver`；源码浏览器模式使用仓库的 `data/.weaver/`。

遇到问题时，按对应入口检查：

- 启动页提示服务失败时，打开 **查看诊断**。处理日志中的缺失项后点击 **重试**。
- 模型不可用时，检查模型文件、采用路径和运行环境。不要只看下载状态。
- 制作失败时，在 **任务** 中查看错误。修正输入或配置后，恢复未完成步骤。
- 提示修订冲突时，保留草稿并对照当前修订，再决定如何采用修改。点击保留草稿后仍可编辑；等待备份期间产生新编辑时，界面会保留这些编辑并提示再次确认加载。

使用正式桌面包与外部 agent 协作时，在 **设置 → 运行时与路径 → 外部 agent 与命令行** 复制完整命令。让 agent 先读取 `capabilities --json`，核对工作区，并根据返回的 `agentSkills` 读取配套技能。从源码启动的桌面与浏览器开发模式的入口见[开发指南](development.md#使用-cli-与外部-agent-协作)，详细命令见[命令与配置参考](conventions.md)。

CLI 默认输出 JSON。需要终端表格时显式加 `--human`。长作业使用 `--wait`，阶段进度写到 stderr，stdout 仍保留最终 JSON 结果。脚本和 agent 不要解析 stderr 中的进度文本。

项目中的 **复制给 agent** 或 `project brief <id>` 会给出绑定了实际数据目录、配置文件和配置基准目录的完整命令。不要用裸 `weaver` 猜测目标工作区。

Agent 提交制作必须使用已审核计划的修订。`build --plan` 返回 `revision`，确认计划后用 `build --expected-revision <revision> --wait` 制作；发生冲突时重新读取并审核。

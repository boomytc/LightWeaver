# 使用 LightWeaver 制作视频

在 LightWeaver Studio 中，你可以导入已有视频、图片和音频，编排场景、字幕和旁白，再一键制作成片并导出为 MP4 或剪辑工程。建议先跑通一次无模型的示例制作，再按实际需要开启 AI 功能。

想先快速看一遍完整流程，可直接跟着[制作第一部短片](quickstart.md)走一遍。

## 打开桌面应用

收到源码工作区后，可以按[运行与开发指南](development.md)（或请 WorkBuddy 阅读该文档）准备好 Node.js、FFmpeg、ffprobe、Chrome 与项目依赖，再用 `npm start` 或根目录的启动脚本（`start.command` / `start.cmd` / `./start.sh`）启动桌面窗口。

- 制作纯文字卡片、查看已有项目或导出已生成的视频，不需要安装 AI 模型或填写 API Key。
- 本地模型与跨软件交接包（OTIO / 剪映）需要 Python 环境，用到时再按需准备即可。
- 平台支持：macOS 支持 Apple Silicon（M 系列芯片），完整本地模型功能需要 macOS 14 或更新版本（不支持 Intel Mac）。

## 制作第一部片子

想先体验完整制作与导出流程：

1. 在左侧导航进入 **项目**，在右侧点击 **打开示例**，创建由三张固定 3 秒卡片组成的无声示例项目。
2. 在 **画面** 页签下，于底部 **故事板** 选择卡片，并在右侧 **属性检视器** 修改文字或属性。
3. 点击右上角 **保存并制作**（内容已保存时显示为 **制作**，已有当前成片时显示为 **重新制作**）。
4. 底部会切换到 **任务** 面板展示进度；需要继续核对画面时点击 **返回故事板**。
5. 制作完成后，从顶部提示条点击 **查看交付** 进入 **交付** 页签，点击 **导出视频** 即可保存 MP4。

详细操作与说明见[制作第一部短片](quickstart.md)。

### 制作自己的视频项目

1. **新建或打开项目**：回到 **项目** 页，在右侧填写 **片名**、选择 **工作流**，点击 **创建空白草稿**；也可以展开 **打开已有项目包…** 导入他人分享的 `.zip` 项目包或目录。
2. **导入素材**：进入项目后，在左侧 **创作资源 → 素材** 拖入或选择视频、图片与音频。如果需要复用全局资源，可在下方选择 **可选方法** 或 **从素材库采用**。
3. **编排场景**：在底部 **故事板** 点击 `+卡片`、`+静帧` 或 `+视频片段` 添加场景（也可以用空故事板上的快捷按钮），拖动或点击左右箭头调整顺序。
4. **调整画面、声音与时长**：选中任意场景后，在右侧 **属性检视器** 逐项调整：
   - 文字卡片（card）：设置卡片样式、标题与要点；
   - 静帧（still）与视频片段（clip）：选择素材、画面适配方式（完整显示 / 填满画幅），视频片段还可设置截取开始时间与截取时长；
   - 声音与旁白：切换到 **声音** 页签或属性检视器的 **02 · 声音策略与旁白**，选择静音、保留原声、旁白或混音，也可以设置全片背景音乐；
   - 时长与遮罩：设置固定帧长或按旁白长度计时（含超窗处理策略），需要局部遮挡时可在 **04 · 遮罩编辑器** 中添加遮罩。
5. **添加或翻译字幕**：切换到顶部的 **字幕** 页签：
   - 可以选择 **计时方式** 手动编辑，点击 **导入字幕** 导入 `.srt` / `.vtt` 文件，或在完成素材转写后点击 **从转写生成字幕**。
   - 展开 **字幕翻译**，填写 **译文目标语言** 后点击 **生成译文**，逐句预览后点击 **采用译文**（如果翻译期间修改并保存了项目，请重新生成译文再采用）。
   - 如果你删掉了某个场景的旁白，或把视频片段改回 **保留原声** / **静音**，绑定在该旁白上的字幕会一起移除；独立时间轴字幕和源片字幕不受影响。

> **关于预处理素材的来源说明**：如果导入的是由外部工具或 agent 预处理过的素材且附带了来源记录（`provenance`），左侧 **素材** 列表和右侧属性区会显示 **素材来源** 卡片，列出处理说明与参考原片；如果其中标明字幕已嵌入画面，则不能在 **字幕** 页签里逐句改写硬字幕，**字幕** 页签只管理独立字幕轨。旧项目未记录来源的素材不会自动补全。

需要批量生成场景或让外部 agent 参与编排时，建议阅读[场景、时长与采用](concepts.md)和[电影制作技能](../.agents/skills/lightweaver-film/SKILL.md)。

## 按需要配置 AI 功能

打开左侧导航的 **设置 → 模型与供应商**，只配置本次制作实际用到的能力即可。

### 使用画面观察和语音合成（云端模型）

1. 在 **供应商** 栏点击 **ModelBest** 右侧的 **配置**，点击 **获取 Key** 前往 [ModelBest 平台](https://platform.modelbest.cn/)申请 API Key。
2. 把 Key 粘贴到 **ModelBest API Key** 输入框，点击 **保存密钥**。

保存后立即生效，无需重启应用。默认使用 `MiniCPM-V-4.7-35B-A3B` 进行画面观察、使用 `VoxCPM2` 进行语音合成与音色设计；详情页显示 **预设已启用** 时即可直接使用。如果此前修改过模型选择，可点击 **采用 ModelBest 预设** 一键恢复。

- **密钥保存与优先级**：你在桌面设置中保存的 Key 只会写入本地配置文件 `config.local.yaml`（已被 Git 忽略，不会随源码泄露）。配置生效顺序为：本地 `config.local.yaml` > 环境变量 > 内置默认配置。点击 **清除本地配置中的密钥** 后，如果环境变量中设置了同名 Key，会自动回退使用环境变量；否则显示未配置。
- **使用语音合成与音色**：前往左侧导航的 **音色** 页面，你可以上传参考音频并填写或自动转写 **参考文本**，也可以在右侧 **设计试听** 输入声音描述与试听文案，点击 **生成试听**，满意后点击 **保存为新音色**。随后回到项目 **声音** 页签，为场景选择该音色并填写旁白文案。注意：在未保存前切换编辑其他音色，当前未保存的上传文件或试听结果会被清空；误删音色、方法或素材时，可点击提示条上的 **撤销** 恢复。
- **注意**：画面观察结果用于帮你挑选素材与镜头，旁白文案仍由你或外部 agent 编写；云端 API 的用量与计费请在供应商平台管理。

### 使用本地转写、精确字幕或素材检索（本地模型）

1. 在 **设置 → 模型与供应商** 的 **本地模型** 区域，按需要选择模型：
   - **Qwen3-ASR 0.6B Q8_0**：本地语音识别（转写）
   - **EmbeddingGemma 2**：文字与画面检索
   - **Qwen3 ForcedAligner 0.6B**：精确字幕对齐
2. 如果想把模型下载到其他磁盘目录，先在 **模型下载位置** 点击 **更换位置** 选择新目录（已有的模型文件不会自动移动，只影响后续下载）。
3. 点击对应模型右侧的 **管理模型**：
   - **自动下载**：未下载的模型点击 **下载并启用**，LightWeaver 会自动下载权重与缺少的运行组件，校验通过后自动启用。
   - **使用本机已有权重**：点击 **模型路径** 旁的 **选择文件** 或 **选择目录** 指向已有权重，系统会自动校验并采用；如果状态显示为 **已下载** 或 **待启用**，点击 **启用** 即可。
4. 下载和准备期间可在当前卡片或 **任务** 页查看进度；完成后状态会变为 **已启用**。如果中途网络中断或失败，点击重试即可，已经下载且校验通过的文件会自动复用，不用从头再来。

如果准备过程失败，不会启用半成品，也不会覆盖你原本可用的模型设置。如需排查或修复本地运行组件（如 Python 运行环境、`llama-server`、`transcribe.cpp`、`TEN VAD`），请前往 **设置 → 诊断与修复**，使用 **运行组件检查与修复** 中的 **检查并修复**。

## 保存、恢复与转交项目

### 保存与创作方案

- **保存**：将当前对项目、场景、字幕以及 **方案** 页的修改一起写入一个新的项目修订。
- **保存并制作**：先保存当前修改，再基于刚保存的修订启动制作（内容未改动时按钮显示 **制作** 或 **重新制作**）。
- **创作方案（方案页签）**：在 **方案** 页点击 **保存方案蓝图** 只会把方案存为待审草案，不会改变当前时间轴；只有当你确认无误后点击 **应用到当前场景**，方案里的场景才会真正替换到项目中。

### 草稿备份与关闭窗口

- **离开或切换项目**：如果当前有未保存修改，应用会弹出提示，让你选择 **保存并离开**、**保留草稿**、**放弃修改** 或取消。
- **恢复草稿**：如果上次编辑没有保存就退出（或意外中断），下次打开该项目时（列表中会带 **可恢复草稿** 徽标），工作区顶部会出现提示条。点击 **恢复未完成草稿** 即可找回编辑内容，核对后再点击 **保存**（不需要时可点击 **清除备份**）。
- **关闭桌面窗口**：
  - 当前没有排队或运行中的制作/下载任务时，应用会处理完草稿后直接退出并关闭后台服务。
  - 当前有任务正在执行时，关闭窗口会询问处理方式：
    - **后台运行**：先把未保存内容写入恢复草稿，再隐藏窗口让制作或下载继续在后台跑。需要回来时，点击系统托盘图标或在托盘菜单选择 **打开 LightWeaver**；也可以从托盘菜单直接 **退出 LightWeaver**。
    - **停止后台并退出**：处理草稿后停止本地服务与正在执行的任务，退出应用。
    - **取消**：保持窗口打开。

### 导出与交接

在项目顶部的 **交付** 页签中，按需要选择导出格式：

- **导出视频**：导出可播放的 MP4 成片。
- **更多导出 → 导出项目包**：把当前已保存修订连同素材、库资源和记录打成可移植的 `.zip` 项目包，方便发给另一台电脑或归档。在另一台机器上可通过 **项目 → 打开已有项目包…** 导入，导入会创建独立的新项目，不会改动原项目。
- **更多导出 → 导出 OTIO 时间线 / 导出剪映草稿**：导出到外部剪辑软件继续精修（剪映草稿当前适配剪映 macOS 版 11.7.0）。

关于版本选择与文件安全：

- 默认导出 **当前** 分组里的最新成片。如果想导出历史版本（位于 **内容已更新** 或 **历史** 分组），先在该行点击 **选择此版本**，再点导出。状态为 **缺失** 的交付文件不完整，无法导出。
- 每一条可用交付都可以展开 **预览与场景定位**（支持按场景编号跳转播放），以及从 **附加文件** 下载 SRT/ASS 字幕、音频、时间轴数据和制作记录。
- 导出时请指定一个新的文件名或尚未创建的目录路径（在桌面端导出 OTIO 或剪映草稿时，选择保存的父目录即可，应用会在其中新建目录），LightWeaver 不会覆盖目标位置已有的文件或文件夹。如果导出过程因意外中断未完成，建议重新选择一个新的目标路径再次导出。
- 修改项目后记得点击 **保存并制作**（或 **重新制作**），再重新导出视频；仅点击 **保存** 不会改写你之前已经导出的 MP4 文件，烧录进画面的字幕也必须重新制作后才会更新。
- 仅仅打开已有项目和导出之前已经做好的视频，不需要安装 AI 模型或媒体工具；等需要重新制作时再检查相关能力即可。
- 更换电脑或重装系统前，请备份你的项目包与原始素材；API Key 和本地模型权重需要在新环境中重新配置。

## 查找数据与排除故障

### 数据目录

在 **设置 → 存储** 可以看到当前的 **项目数据**、**模型默认位置** 和 **日志** 路径。在桌面应用中，你也可以点击 **更换工作区并重启** 切换到其他目录（原目录中的所有数据都会保留）。

默认数据位置：
- **桌面应用**：系统用户配置目录下的 `LightWeaver/weaver`（例如 macOS 为 `~/Library/Application Support/LightWeaver/weaver`）。
- **浏览器开发模式（`make studio`）与 CLI**：仓库根目录下的 `data/.weaver/`。

### 常见问题排查

- **启动页提示服务启动失败**：点击启动页上的 **查看诊断** 查看服务日志，补齐日志中提示的缺失依赖（如 Node.js 或媒体工具）后，点击 **重试**。
- **模型下载或启用失败**：在 **设置 → 模型与供应商** 重试；若怀疑运行组件损坏或缺失，打开 **设置 → 诊断与修复**，点击 **运行组件检查与修复** 中的 **检查并修复**。
- **制作或分析任务失败**：在底部或左侧导航打开 **任务** 页查看具体报错与修复建议，调整输入或配置后，点击 **继续任务** 或重新提交。
- **出现修订冲突提示**：如果在你编辑期间，外部 agent 或其他入口保存了新的项目修订，工作区顶部会提示“另一处已经更新了这个项目”，同时完整保留你的本地草稿，不会直接覆盖。先点击 **查看差异** 对照本地草稿与服务器最新内容；确认需要更新后，点击 **保留我的草稿并加载服务器内容**（并在弹窗中点击 **备份草稿并加载**），先把本地草稿保存为可恢复备份再加载最新修订，随后在最新修订上按需要补入改动（必要时可从项目列表恢复原草稿备份继续对照）。

## 请外部 agent 协助创作

如果你想让外部 agent（例如 WorkBuddy）帮你分析视频素材、撰写分场脚本、导入预处理媒体或批量修改项目：

1. 在 Studio 中打开目标项目，点击右上角 **更多 → 复制给 agent**。
2. 把剪贴板里的完整交接文本发给你的 agent。

复制出的内容已经包含绑定到当前项目数据目录和配置文件的完整命令入口，能避免 agent 误操作到其他工作区。关于 CLI 环境调用与 agent 技能约定，可进一步查看[使用 CLI 与外部 agent 协作](development.md#使用-cli-与外部-agent-协作)、[LightWeaver 入口技能](../.agents/skills/lightweaver/SKILL.md)以及[命令与配置参考](conventions.md)。

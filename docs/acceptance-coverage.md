## 审查修复

采用边界统一保留窗口外字幕，合并后按全部 cue 计算计时质量。完整恢复原文清除翻译语言；局部原文与剩余译文混用会拒绝。translationSourceText 保存人工修正后的实际翻译输入，重复翻译复用这份文字，sourceText 继续保存原始转写。音频或视频作为导入旁白时，源字幕按实际语音时钟映射；同一场景和源版本只映射一次。未选入成片的源窗不生成字幕。创作方案的未采用依赖进入保存和 bundle，制作只使用已采用场景；证据引用随包重映射。

分析结果只在作业成功事务中发布，证据身份包含实际结果摘要，同一标识不能覆盖不同内容。视觉图像缓存还绑定 FFmpeg 版本。本地语音按官方模式区分风格控制和参考文本续写，冻结模型、适配代码、解释器与实际安装包字节。

## 证据边界

这些是功能和生命周期验收，不是模型质量排名。画面查询只验证少量真实视频的正确排序，未量化长片、稀疏事件或复杂语义召回。Hy-MT2 将“喂马，劈柴”误译为 `Hello, horse. Chop wood.`，因此译文保留审阅和人工修改入口。MOSS 标签不代表人物身份，也不承诺跨窗口一致。

水果视频开头只转写出语气词，强制对齐拒绝空句界。此失败保留为能力边界，没有降级成 estimated 后标记 aligned。克隆音色相似度、情绪服从度和字幕译文质量没有做量化评测。

最终 `npm run typecheck`、`npm run build -w @lightweaver/studio`、Python 语法和 `git diff --check` 通过。构建只报告已有 Zod 依赖的 Rollup 注释警告。

精简审计限定当前 diff，字幕编辑只移除失效 words 的逻辑改为保留其余字段的解构；修改后再次通过浏览器保存与数据库核对。没有新增或删除永久测试，临时用例与媒体按仓库约定清理。保留产品诊断、schema、边界和类型检查。临时页面、服务和状态已清理，本地模型环境与必要运行文件保留。

# 制作第一部短片

这篇教程带你用内置示例在桌面应用中做出第一部短片并导出 MP4。示例由三张纯文字卡片组成，不需要自备视频、图片，也不需要配置 AI 模型、API Key 或 Python 环境。

示例共有 3 张卡片，每张固定 90 帧；在默认的 1920×1080、30 fps 规格下，每张卡片播放 3 秒，整片共 9 秒。

## 准备并打开应用

1. 首次使用前，先按[运行与开发指南](development.md)准备好 Node.js（22.13+ 的 22.x 或 24.x）、FFmpeg、ffprobe 和 Chrome，并在项目根目录运行 `npm ci` 安装依赖。
2. 在项目根目录运行 `npm start`（macOS 也可双击 `start.command`，Windows 双击 `start.cmd`，Linux 运行 `./start.sh`）打开桌面应用。

## 从首页打开示例

1. 在左侧导航点击 **项目**。
2. 在右侧 **新建项目草稿** 栏中，点击 **打开示例**。
3. 等待应用打开名为「我的第一支视频」的示例项目。底部的 **故事板** 中已有三张卡片，此时还没有生成成片。

## 修改卡片文字并制作

1. 在底部 **故事板** 中选中第一张卡片，在右侧 **属性检视器** 修改 **标题** 或 **要点**。
2. 点击右上角 **保存并制作**（如果你刚才已经点过 **保存**，按钮会显示为 **制作**；已有成片后会显示为 **重新制作**）。
3. 底部工作区会自动切换到 **任务** 标签，实时显示准备、渲染和封装进度。制作过程中如果想回去核对文案，点击 **返回故事板** 即可。

如果保存失败，制作不会提交，界面会直接提示错误原因，不会把未保存的草稿当成成片。

## 查看交付并导出 MP4

1. 制作完成后，工作区顶部会出现绿色提示条，点击 **查看交付**（也可直接点击顶部的 **交付** 标签）。
2. 在 **交付与历史** 的 **当前** 分组中确认刚生成的成片（默认已选为导出版本）。你可以展开 **预览与场景定位** 先播放一遍。
3. 点击左上方的 **导出视频**，选择保存目录并输入新的文件名（例如 `first-film.mp4`）。
4. 导出完成后，在目标文件夹打开 MP4 播放即可。

> **说明**：如果目标位置已有同名文件，LightWeaver 不会覆盖原文件，请换一个新的文件名。示例中的三张卡片没有声音轨，因此导出的 MP4 是无声视频，这是正常现象。

## 想用命令行或交给外部 Agent 来做？

在工作区根目录运行下面这行命令，就能在 CLI 中创建同样的三卡片示例项目（CLI 默认使用仓库下的 `data/.weaver/` 目录）：

```sh
npx weaver project create first-film --sample --json
```

如果你想让外部 agent（例如 WorkBuddy）协助操作**桌面应用里已经打开的项目**，请先在项目右上角点击 **更多 → 复制给 agent**，把复制出来的完整命令交给它，这样它会自动连到正确的数据目录和配置文件。

完整的 CLI 命令参数、制作前计划审核与批量编辑流程，见[电影制作技能](../.agents/skills/lightweaver-film/SKILL.md)与[命令与配置参考](conventions.md)。

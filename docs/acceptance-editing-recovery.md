# 编辑与恢复边界验收

2026-11-01，基线 `3498d31`。范围为冲突草稿恢复、视觉遮罩、场景关联引用和备份恢复。基线源码由 Git 归档到系统临时目录，验收使用隔离配置、合成媒体和独立项目，未改动用户项目或原始媒体。

## 冲突恢复

通过临时反向代理挂起真实 Studio 备份请求。旧实现中，点击“保留草稿并加载当前修订”后继续修改标题，放行请求会将标题换成服务器内容，并清除 dirty。修复后，同一时序保留新标题、dirty、冲突及原修订基线，客户端备份包含新标题。再次确认且期间没有编辑时，可以正常加载服务器修订。

等待前固定项目、会话代次、文档与方案序号、修订基线，每次异步返回后检查。独立复审补出并发成功保存推进修订、但草稿序号不变的情况。浏览器对照中暂停保存后的 context 重载，确认旧加载操作会使已保存的新标题和修订回退；加入基线守卫后，相同时序保持最新标题和修订。原生 journal 清理失败的错误提示也限制在原项目与会话内，此项核对了代码路径，未单独注入 Electron 原生清理故障。

## 视觉遮罩

真实 Remotion 与 FFmpeg 制作同一份 320×180、12 fps 的 card、clip、still 工程，三场均添加全屏红色遮罩。旧实现制作成功，但卡片抽样像素约为 `[180,180,182]`，另外两场为 `[255,25,0]`。修复后三场均为 `[255,25,0]`，统一处理遮罩；RGB 差异用于判断画面是否被覆盖，不作为色彩质量评测。

所有视觉分段在输入与画幅准备后共用遮罩滤镜和编码出口。无遮罩卡片继续复制原渲染结果。有遮罩卡片重新编码，仍经过原有规格、帧数与无音轨校验。渲染算法升为 `unified-ffmpeg-v7-visual-masks`，进入冻结绑定与缓存键。

## 场景关联引用

CLI 因果对照使用包含真实导入音频、speech 字幕及保留字幕的有效工程，删除前制作成功。基线删除场景后仍保留关联字幕，随后制作返回 `CAPTION_SCENE_MISSING`；修复后清理关联 speech cue，删除前后均制作成功。另验证了 source、timeline 字幕及轨道设置保留，对应已删场景的遮罩被清理。

`reconcileSceneReferences(previous, next)` 作为共享纯规则接入整份项目更新、操作列表最终结果及 Studio 通用草稿编辑。只清理此前存在而最终被删除的场景，不吞掉新提交的非法引用；保存边界拒绝残留的失效字幕或遮罩引用。操作顺序、同 ID 删除后重加及创作方案隔离由临时窄验证覆盖。

实际 Studio 从故事板删除带导入旁白的场景，保存前字幕页仅保留另一条字幕，保存后的工程只有保留场景的遮罩；继续点击制作，作业成功。

## 备份恢复

真实媒体项目执行 backup，基线清空 `backup.json` 的 blob 列表后仍报告 restore 成功。修复后，数据库 `blob_refs` 与 `blobs` 提供实际依赖及元数据，备份与恢复共用该查询。清单集合必须与数据库引用一致，文件复制到暂存目录后逐一核对大小与 SHA-256，再发布目标目录。

实际 CLI 验证清空或漏掉一项、重复项、额外无引用项、bytes 或 MIME 不符、文件缺失、同大小内容损坏及数据库引用缺少元数据，均返回 `INTEGRITY_FAILED`，不留下发布目录或暂存目录。完整备份正常恢复，引用媒体保留，瞬态操作 pin 被清理。

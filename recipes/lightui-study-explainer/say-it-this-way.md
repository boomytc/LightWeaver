# 说清楚

`kind=close` 钉在末尾。`closeCard.headline`：`说清楚` / `Say it this way`。lede 只当小节标题（如「最容易混的一对」）。正文写 `points`：易混对用 `左 || 右` 做成对照块，再补一条「先名称场景规则，再谈外观」。不要一段 lede 当正文，不要 mermaid / 第二套渲染器。

易混对也用听者的话：讲动作和后果，不要回滑到实现词（叶子、提交模型、安全三角、走廊、sticky、观察器）。四则 `close` 都是这个收束，不是 CTA、不是品牌秀。禁止 `scene add --kind close`。

# 创作边界

任务提供画面、源视频或文字目标。方法、音色、素材库都是可选增强。上下文足够时直接制作；只有缺失信息影响创作意图时才提问。

长视频先按时间窗分析，再读取按源时间排序的证据。多源剧情、无对白观察、文案检索与参考匹配分别保留来源。模型返回的观察不自动写入旁白。

先区分原片和参考片，检查时长、音轨、画面中的字幕及各自用途。多个参考可能剪辑不同，明确哪份决定画面、声音和字幕。只有这项差异影响目标且无法从任务判断时，才澄清。时长接近不能证明镜头相同，文件名和字幕语言也不能证明对白语言。

按选定基准运行 `match --project <id> --edited <ref-id> --sources <source-id,...> --wait --json`。审核候选的源窗、参考区间、匹配方式和警告；无音轨的参考可以只用视觉证据。有原文时可显式导入证据。未经逐镜头核验的结果按近似复刻描述。

用户要求复刻参考时，选材范围以明确的参考内容为依据。说明已用和未用原片及理由；参考封面是否进入成片取决于目标，不把素材全部用完作为完成条件。

优先使用原片场景、独立导入音频和独立字幕轨，保留 Studio 的编辑能力。只有交付需要保留画面中的字幕或必须预处理时才使用合成素材，并按素材技能记录来源和字幕状态。嵌入画面的字幕不能直接变回可编辑字幕；需要文字轨时，从可用转写、用户字幕或人工校对稿建立，缺少文字来源时明确说明。
